6. 经验总结

  1. 数量字节不在道具槽内：道具槽 $0410-$04B7 只存 ID、冷却计时器、动画参数，数量在 $0204。
  2. 全 RAM 快照对比最直接：使用前/后快照 diff 全内存，比持续监控更干净。
  3. 回调可覆盖写入：addMemoryCallback 写回调返回值覆盖原写入，可做运行时验证。
  4. emu.getState() 取 PC：在回调中调用获取 cpu.pc，定位写入指令的 ROM 地址。
  5. DEC $0200,X 是唯一点：全 ROM 仅 1 处，NOP 掉即可阻止所有道具减少。
  6. API 参数必须写全：缺 cpuType/memType 会 core dump，枚举是 emu.callbackType.write。
